## Overview

Interactive AI assistant designed to eliminate bureaucratic bottlenecks by synthesizing official government documentation into instant, step-by-step guidance.

## Architecture

- **Contextual Prompt Engineering:** Integrated Gemini API with grounded context prompts to avoid hallucinations.
- **Workflow Pipeline:** Engineered structured Django backend pipelines to process queries, validate inputs, and monitor rate limits.
